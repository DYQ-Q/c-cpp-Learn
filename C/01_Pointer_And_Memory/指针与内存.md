# 指针与内存

> Stage 1 语言地基 ｜ 目录 `C/01_Pointer_And_Memory/` ｜ 计划：**第 2 批**（当前为骨架）

## 一句话定位
C 里指针就是地址，`sizeof(指针)==sizeof(size_t)`。所有"高级特性"（数组退化、多维展平、柔性数组、函数指针）都是这条事实的推论。

## 待覆盖小节
- 指针运算与 `ptrdiff_t` / `size_t`
- 数组名 vs 指针：`int a[5]` 与 `int *p=a` 的 `sizeof` / `_Addressof` 差异
- 多级指针、`int (*f)(int)` vs `int *f(int)` vs `int *a[5]`
- 对象表示：`unsigned char *` 窥探、字节序实测
- 柔性数组 `struct { size_t n; int v[]; }`
- 严格别名与 `memcpy` 破法（详见 `02_Type_System`）

## 骨架示例
```c
#include <stdio.h>
int main(void) {
    int a[5] = {0,1,2,3,4};
    printf("sizeof(a)=%zu sizeof(a+0)=%zu\n", sizeof a, sizeof(int*));
    printf("a+2 - a = %td, *(a+2) = %d\n", (ptrdiff_t)(a+2) - (ptrdiff_t)a, *(a+2));
    return 0;
}
```
