# 系统编程

> Stage 5 ｜ `C/18_System_Programming/` ｜ 计划：**第 6 批**（骨架，POSIX 部分建议配 WSL）

## 一句话定位
系统编程是"从 libc 掉到 syscall"。Windows 与 POSIX 在这里**不是同一套 API**，所以内容会明确标注平台归属。

## 待覆盖
- 进程：`fork/exec`（POSIX）、`CreateProcess`（Win）、退出码与管道
- 文件描述符 vs `FILE*`、`stat`、目录遍历、文件锁
- 信号：`signal`/`sigaction`、异步信号安全、优雅退出
- Socket：TCP/UDP、`select`/`poll`/`epoll`(Linux)、IOCP(Windows)、Reactor 模式
- 内存映射文件、时区与本地化、环境变量与命令行解析
- Windows 控制台编码（`SetConsoleOutputCP`，替代 `chcp >nul`）
