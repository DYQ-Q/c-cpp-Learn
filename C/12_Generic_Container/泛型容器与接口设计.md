# 泛型容器与 C 风格接口设计

> Stage 2 ｜ `C/12_Generic_Container/` ｜ 计划：**第 4 批**（骨架）

## 一句话定位
C 没有模板，只有 `void*` + 函数指针 + 约定。**谁持有内存**必须由接口文字写明，否则必崩。

## 待覆盖
- `qsort`/`bsearch` 的 `void*` 比较器与 `compar` 返回值约定
- 三条泛型路线：`void*`（运行时、类型不安全）、宏生成（`#define VECTOR_OF(T)`）、`_Generic`
- 侵入式容器（`container_of` 宏、内嵌 `struct list_head`）
- 不透明指针 / 句柄、`*_create/*_destroy` 配对
- 所有权语言：borrow / transfer（`free` 归谁）
- 错误传递：返回码、`errno`、`setjmp/longjmp`、全局 last-error
