# 链表

> Stage 2 数据结构 ｜ `C/07_DS_List/` ｜ 计划：**第 3 批**（骨架）

## 一句话定位
链表是**指针语义的期末考**：二级指针删除、哨兵节点、`const` 正确性、内存所有权，一个都躲不掉。

## 待覆盖
- 单向 / 双向 / 循环 / 跳表
- `**head` 删除技巧（免特判头节点）、哨兵节点
- 逆置、快慢指针找中点、环检测与入环点（Floyd）
- 合并 K 个有序链表
- 用**侵入式链表**（`struct list_head` 内嵌）实现 O(1) 通用删除——Linux 内核写法
- 每一步都跑 ASan/Valgrind 等价检查，验证零泄漏
