# 字符串与编码

> Stage 1 ｜ `C/05_String_Encoding/` ｜ 计划：**第 3 批**（骨架）

## 一句话定位
`char*` 只是一段字节，**编码是约定不是类型**。中文乱码、`strlen` 数出 3、Windows 控制台打印方块，全部源于把"字节"当"字符"。

## 待覆盖
- 字面量编码 vs 执行字符集：`-finput-charset` / `-fexec-charset`
- ASCII / UTF-8 / UTF-16 / GBK 的字节布局；UTF-8 前导字节算法规则
- `strlen` 陷阱；`strcpy`/`strncpy`/`snprintf` 安全性对比
- `<string.h>` 全族、`strtok` 的可笑设计、`strerror` 线程不安全性
- C11 `<uchar.h>`：`char16_t`/`char32_t`/`u8u16u32c32rtomb`
- Windows `wchar_t`(2字节) vs POSIX(4字节)、`SetConsoleOutputCP`
- 手写 UTF-8 ↔ codepoint 编解码器（本目录主项目）
