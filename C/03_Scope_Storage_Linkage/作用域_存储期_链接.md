# 作用域、存储期与链接

> Stage 1 ｜ `C/03_Scope_Storage_Linkage/` ｜ 计划：**第 2 批**（骨架）

## 一句话定位
三个独立维度，90% 的 `multiple definition` / `undefined reference` / "改了头文件没生效"都源自把它们混为一谈。

## 待覆盖
- 作用域(编译期可见性) vs 存储期(对象活多久) vs 链接(跨 TU 可见性)
- `auto`/`static`/`extern`/`thread_local`/`register`
- 声明 vs 定义、tentative definition、`extern int n;` 放在 `.h`、`int n;` 只放一个 `.c`
- 内部链接 `static`、外部链接、`inline` 的三种流派（C99 语义坑）
- 名字遮蔽、`struct` 标签命名空间、GCC `__attribute__((visibility))`
- `extern "C"` 为什么需要（C++ name mangling）——与 `C++` 目录交叉
