# 树：二叉树 / BST / AVL / 堆

> Stage 2 ｜ `C/09_DS_Tree/` ｜ 计划：**第 4 批**（骨架）

## 一句话定位
树的代码量小、认知负荷大：递归三形态（前中后）、旋转的不变式、堆的下沉，写错一个指针就静默错。

## 待覆盖
- 遍历：递归 / 显式栈 / Morris（O(1) 空间）
- BST 插入删除（**删除四种情况**）、验证 BST（上下界法 vs 中序）
- AVL：四种旋转、平衡因子；红黑树为何工程上更常用
- B 树/B+ 树：为什么数据库和文件系统用它（磁盘块与局部性）
- 堆：数组表示、`sift_down`、Top-K、外部排序
- Trie：字符串前缀、字典树 vs 哈希表取舍
- 线段树 / 树状数组入门
